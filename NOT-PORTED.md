# What’s different from the PS5 version

Orbit Store for PS4 brings the PS5 version’s features to the PS4: the catalogue, download providers, add-ons, archive unpacking, package installation, Files, Library, phone pairing, updates, four interface layouts and 26 languages.

**Orbit Zero isn’t included.** The desktop app and its transfers to the console are PS5 only.

Some parts work differently on PS4:

- The TV app is a PS4 package, `orbit_store_ps4.pkg`, installed with GoldHEN’s Package Installer.
- Orbit installs PKG and FPKG games with the PS4’s own package installer.
- Library reads the games installed on the PS4 itself. ShadowMount game images and game folders aren’t available on PS4, so Library can’t mount, copy or move games.
- The catalogue lists PS4 games only.

See [Getting started](guides/getting-started.md) to set it up.
