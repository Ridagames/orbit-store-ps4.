# Orbit Store 0.1.0 (Beta)

> **🎉 OrbitNet is coming soon: online multiplayer for jailbroken PS5s.** From the developer of Orbit. Follow along at [getorbitnet.com](https://getorbitnet.com).

**Orbit can now get a game with its update and DLC in one go, and can also keep your games up to date with the new updates page.**

## Orbit Store · PS4

- **Get everything.** On a PS4 game’s page, **Get everything** lists the game, the newest update your PS4’s firmware can run and the game’s DLC. Untick what you don’t want and select **Download all**. Orbit downloads them and installs them in order: the game, then the update, then the DLC.
- **Update your games.** Library shows the version of each installed game and marks the ones with a newer update. The **Updates** view lists them all: select **Update** on a game, or **Update all**. Updates download and install by themselves. Orbit has updates for 410 PS4 games, including backports for older firmware.
- **300 more games.** Orbit now has **1,734 PS4 games with 1,851 download options**, plus **564 add-ons with 566 options across 125 base games**.
- **More scores and playtimes.** 543 PS4 games now show a Metacritic score and 932 a HowLongToBeat playtime, up from 433 and 742.
- **Archives.** Orbit can now keep ZIP, 7z and RAR downloads packed: turn off **Extract archives after downloading** in Storage settings. When it unpacks them, RAR archives now use RARLAB’s UnRAR and several of the PS4’s CPU cores. A ZIP, 7z or RAR download now needs room only for itself when you add it. Orbit checks for room for its files just before unpacking; if there isn’t enough, the download waits with the archive kept until you free up space and select **Resume**.
- **Covers stay after a restart.** Orbit keeps the covers it has downloaded, so the TV app doesn’t fetch them again after the PS4 restarts.
- **TorBox fixes.** Orbit stops waiting when TorBox can’t get a file, and sends a request to TorBox again if the first one never arrived. **Always use TorBox** now applies only to downloads TorBox can get. Others use their original source. If a TorBox download fails before it starts and you remove it, you can now download that game again.
- **Orbit’s address on start-up.** The start-up notification shows the address to open Orbit in a browser.
- **Network drops.** Orbit no longer closes when the PS4’s network drops.
- **Back to Orbit after a download page.** When a Vikingfile or AkiraBox page closes, the TV app comes back to the front instead of the PS4 home screen.
- Other improvements and bug fixes.

## Orbit Zero · Mac, Windows and Linux

- **Get everything and Update with your PS4.** Zero shows the same **Get everything** checklist on PS4 game pages, and the update badges, the **Updates** filter and **Update all** in Library. The PS4 downloads and installs them itself. Needs Orbit Store 0.1.0 on your PS4.

## What you need

A PS4 with GoldHEN. Turn on GoldHEN’s payload loader once, in **GoldHEN → Servers Settings → Enable PayLoader Server**, so Orbit can start. For Orbit Zero, a Mac, Windows or Linux computer on the same home network as your PS4, over Wi-Fi or Ethernet.

## Install or update the native TV app (PKG)

Download `orbit_store_ps4.pkg` from **Assets**, verify its `.sha256`, and copy it to your PS4 on a USB drive. Install it with GoldHEN’s **Settings → Debug Settings → Package Installer**, then open **Orbit Store** from the Games row. Native app **0.1.0** includes the matching Orbit Store **0.1.0** service and elfldr.

Close other apps such as ezRemote before opening Orbit. With them open, the PS4 may not have enough memory left to start it.

## Use Orbit Zero with your PS4

Download the `Orbit-Zero-1.9.5-*` package for your computer from **Assets**: macOS DMG, Windows installer or ZIP, or Ubuntu/Debian DEB, for ARM64 or x64. Open Orbit on your PS4, then in Orbit Zero go to **Settings → Devices**, enter your PS4’s IP address, select **Connect to Orbit** and enter the code shown on your PS4. [Step-by-step guide](https://github.com/saawant12/orbit-store-ps4/blob/main/guides/orbit-zero.md)

Orbit Zero 1.9.5 works with your PS5 too.

## Use the browser version (ELF)

Download `orbit_store.elf` and its `.sha256` from **Assets**, verify the checksum, then send the ELF once to an ELF loader on port 9021, such as elfldr. GoldHEN’s own payload loader on port 9090 can’t run it; it’s too big. Orbit saves its service and elfldr, and adds the **Orbit Store Browser** icon. Open it, or `http://<ps4-ip>:34177/` on another device on the same local network.

To start Orbit when the PS4 turns on, see [Payload manager and auto-start](https://github.com/saawant12/orbit-store-ps4/blob/main/guides/getting-started.md#payload-manager-and-auto-start).

## Good to know

- **Get everything installs in order.** Each download waits for the one before it to install. If one fails or isn’t installed, the ones after it stay downloaded and wait for you to install them from Downloads.
- Updates are offered only for the title ID of the installed game, so a copy from another region gets none. Orbit can’t tell which DLC you already have, so Get everything ticks all of it; untick what you have.
- Right after the PS4 turns on, Orbit sometimes needs a second try to start. The app and the auto-start copy try again by themselves, so the first start can take up to about 40 seconds longer.
- **Without Orbit Zero, Vikingfile and AkiraBox still take a few minutes.** On PS4, the Cloudflare check on their pages can take 2–3 minutes to pass. Leave the page open: once the check passes, the download works as usual. With a Vikingfile Premium account [signed in to Orbit](https://github.com/saawant12/orbit-store-ps4/blob/main/guides/vikingfile.md), there’s usually no wait.
- AkiraBox may show an ad instead of the download. Close it and try again, or choose another source for the game.
- Orbit Zero uses one console at a time. Finish or cancel the transfers to one console before switching to the other.
- Scores and playtimes come from published Metacritic and HowLongToBeat data. Games without them show none; playtimes are community estimates and vary by player.

## Downloads and source

- **PS4:** `orbit_store_ps4.pkg` includes the native TV app, the download service and elfldr. Use `orbit_store.elf` to run the service and browser interface on their own.
- **Mac, Windows and Linux:** choose the `Orbit-Zero-1.9.5-*` package for your operating system and processor. Orbit Zero includes Orbit for PS5 1.9.5, whose source code is in `orbit-store-1.9.5-source-bundle.zip` in this release’s **Assets**, and elfldr a481740, whose source code is in `orbit-store-0.1.0-source-bundle.zip`.
- **Source code:** `orbit-store-0.1.0-source-bundle.zip` includes the Store source code, dependencies, elfldr’s source, licence notices and build instructions.
- **Checksums:** use `SHA256SUMS` to check your download, or run `shasum -a 256 -c <filename>.sha256` for the ELF or PKG.
